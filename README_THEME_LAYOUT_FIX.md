# Theme / Admin Layout Follow-up

Changes in this build:

- Admin sidebar is fixed to the viewport on desktop and remains a slide-in drawer on mobile.
- Desktop admin content is offset by the 240px sidebar so it never sits underneath it.
- The admin dashboard background gradient is visible again because the dashboard shell/content is transparent over `dashboard-bg`.
- Dashboard light-mode green gradient was restored with a slightly stronger green start.
- Dashboard dark-mode green gradient remains preserved.
- Dashboard header uses a translucent surface so the gradient can show through.
- Header bottom border is subtler (`border-line/40`), and dark-mode line color is reduced for a quieter divider.
